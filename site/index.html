SOUND PACK

Small engine. Many roles.

Each profile combines its sources under a shared pitch and envelope. IDs 08–11 use 1.2-second piano recordings without a default saw body. ID 25 is Strings, using a licensed SoundFont sample: raise ATTACK for a slower onset.

These are design goals, not claims of realistic instrument reproduction or approved sound quality. The files below are host renders from the shared C core. Hardware testing and listening approval are still pending.

Hear the full sound pack

Start with the original MC-1 demos: NIGHT CIRCUIT (an 8-bar pattern excerpt) and NEON SPIRAL (32 bars), with new voices in matching roles. Then hear all 32 presets, 8 drum kits, two additional dance songs, and the stress render as MP3 previews. Lossless C renders are retained as local engineering evidence.

Timbre revision in progress: The current bank has not met the listening standard for richness. These files are reference candidates, not approved sounds. Revised presets will be evaluated as complete source, filter, envelope, and built-in FX combinations.

Comparison conditions: Fixed render gain, with no loudness matching or normalization. Differences in playback level are not a sound-quality score.

Every example comes from the same host C renderer. Device output and real-time performance have not been tested, and listening approval is pending. Measurements and downloadable files do not constitute sound-quality approval.
