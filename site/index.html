작은 엔진, 넓은 역할

베이스, 하이브리드 키, 플럭, 컴프, 리드, 패드와 모션까지. 각 프로필은 공유 피치와 엔벌로프 아래 필요한 발음 요소를 조합합니다. ID 08은 FM이 더해진 synth piano, ID 09는 piano 어택 뒤 strings/pad 성격이 남는 piano+strings 방향입니다.

이 설명은 설계 의도이지 사실적인 악기 재현이나 음질 승인을 약속하지 않습니다. 아래 파일은 공통 C 코어가 렌더한 호스트 오디오이며, 기기에서는 시험하지 않았고 실제 청취 승인은 아직 이뤄지지 않았습니다.

FULL AUDIO GALLERY

전체 오디션

빠른 댄스송 두 곡, 128 BPM 힙합과 144 BPM 테크노로 전체 느낌을 먼저 들어보세요. 프리셋 32개, 드럼 킷 8개, 개별 데모와 스트레스 렌더도 재생하거나 WAV로 내려받을 수 있습니다.

비교 조건: 고정 게인으로 렌더했습니다. 음량 매칭이나 정규화는 하지 않았으므로 파일 간 크기를 음색 품질 비교로 해석하지 마세요.

모든 예시는 같은 호스트 C 렌더러에서 생성됐습니다. 장치 출력·실시간 동작은 시험하지 않았고, 주관적 청취 승인은 완료되지 않았습니다. 수치나 파일 제공은 음질 승인이 아닙니다.
